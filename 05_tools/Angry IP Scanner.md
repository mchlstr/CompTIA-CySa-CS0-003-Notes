# Angry IP Scanner

## What it is
Lightweight network scanner for discovering live hosts and basic host info.

## Purpose
Quickly enumerate active hosts and open ports on local networks for reconnaissance and inventory.

## Key Features
- Fast scanning of IP ranges  
- Hostname, open port, and basic service detection  
- Export results to CSV

## Practical Use Cases
- Initial asset discovery during assessments  
- Quick checks for online hosts during troubleshooting  
- Creating lightweight host lists for deeper scanning

## Tips
- Not a full vulnerability scanner — combine with Nmap/OpenVAS for depth.  
- Useful for quick adhoc discovery but avoid aggressive scanning on production.
