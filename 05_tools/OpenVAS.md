# OpenVAS

## What it is
Open-source vulnerability scanner and manager.

## Purpose
Scan networks and hosts for known security weaknesses and compliance gaps.

## Key Features
- Network vulnerability scanning  
- Automated reporting  
- Integration with threat intelligence feeds

## Practical Use Cases
- Routine vulnerability assessments  
- Compliance scanning  
- Prioritizing remediation efforts

## Tips
- Requires setup and tuning for large networks  
- Combine with Nmap for asset discovery
