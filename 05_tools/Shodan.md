# Shodan

## What it is
Search engine for Internet-connected devices.

## Purpose
Identify exposed services, misconfigurations, and vulnerabilities across the Internet.

## Key Features
- Search devices by IP, port, or service  
- Filters for country, product, or organization  
- API for automated queries

## Practical Use Cases
- Reconnaissance for penetration testing  
- Monitoring public-facing infrastructure  
- Threat intelligence gathering

## Tips
- Do not scan or exploit discovered devices without permission  
- Use Shodan data for situational awareness
