# tcpdump

## What it is
Command-line packet capture tool for network traffic analysis.

## Purpose
Capture and inspect packets to troubleshoot networks and analyze threats.

## Key Features
- Capture TCP, UDP, and ICMP traffic  
- Filtering by IP, port, protocol  
- Output to files for offline analysis

## Practical Use Cases
- Network troubleshooting  
- IDS/IPS testing  
- Packet-level threat hunting

## Tips
- Use capture filters to reduce data volume  
- Combine with Wireshark for GUI-based analysis
