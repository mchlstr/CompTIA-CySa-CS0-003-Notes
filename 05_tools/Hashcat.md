# Hashcat

## What it is
Advanced password recovery and cracking tool.

## Purpose
Test password strength and recover lost passwords using brute force, dictionary, and hybrid attacks.

## Key Features
- Multi-hash support (MD5, SHA, NTLM, etc.)  
- GPU acceleration for faster cracking  
- Extensive attack modes and rules

## Practical Use Cases
- Test password policies  
- Recover forgotten credentials in lab environments  
- Security assessments for stored hash protection

## Tips
- Use only in legal testing environments  
- Combine with wordlists and rules for realistic simulations
