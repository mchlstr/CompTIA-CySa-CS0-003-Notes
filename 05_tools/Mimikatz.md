# Mimikatz

## What it is
Post-exploitation tool for credential extraction on Windows systems.

## Purpose
Retrieve plaintext passwords, hashes, and Kerberos tickets from memory.

## Key Features
- Extracts NTLM hashes and cleartext passwords  
- Pass-the-Hash and Golden Ticket attacks  
- Kerberos ticket manipulation

## Practical Use Cases
- Red team exercises  
- Security assessments of credential storage  
- Testing domain controller protections

## Tips
- Extremely powerful, use only in lab or authorized environments  
- Often flagged by antivirus and EDR
