# OWASP Zed Attack Proxy (ZAP)

## What it is
Open-source web application security scanner and proxy.

## Purpose
Intercept and test HTTP/S traffic to identify vulnerabilities.

## Key Features
- Active and passive scanning  
- Interception proxy for request/response modification  
- Extensible via scripts and plugins

## Practical Use Cases
- Automated security testing in CI/CD  
- Learning web vulnerabilities  
- Penetration testing of web applications

## Tips
- Use with local or staging apps  
- Regularly update to latest rules and scripts
