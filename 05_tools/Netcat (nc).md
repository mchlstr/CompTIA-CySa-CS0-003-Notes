# Netcat (nc)

## What it is
Versatile networking utility for reading and writing raw network connections.

## Purpose
Test connectivity, transfer files, and set up simple network services.

## Key Features
- TCP/UDP connectivity  
- Port scanning and banner grabbing  
- Simple reverse shells for lab exercises

## Practical Use Cases
- Debug network services  
- Quick file transfer between hosts  
- Educational demonstrations for sockets

## Tips
- Avoid using on unauthorized networks  
- Often used in conjunction with other penetration testing tools
