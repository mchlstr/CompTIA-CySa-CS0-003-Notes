# Zeek

## What it is
A hybrid network monitoring tool that passively monitors network traffic, similar to a packet sniffer, but logs only data of potential interest for analysis.

## Purpose
Provide deep network visibility and security monitoring by analyzing network flows, detecting anomalies, and logging events for threat detection.

## Key Features
- Formerly known as Bro  
- Passive network monitoring and analysis  
- Protocol-specific logging for HTTP, DNS, SSL/TLS, and more  
- Detect network anomalies, suspicious traffic, and policy violations  
- Integrates with SIEMs and security pipelines  

## Practical Use Cases
- Monitor network traffic for unusual behavior or attacks  
- Detect lateral movement and command-and-control communication  
- Generate rich logs for incident response and forensic analysis  

## Tips
- Use with centralized log storage for long-term analysis  
- Leverage custom scripts to extend detection capabilities  
- Combine with packet capture tools (e.g., Wireshark, tcpdump) for deeper inspection
