# Aircrack-ng Suite

## What it is
Set of tools for assessing Wi‑Fi network security: capture, crack, and analyze wireless traffic and keys.

## Purpose
Test wireless network security, discover weak encryption, and validate Wi‑Fi configurations.

## Key Features
- Packet capture and replay tools (airodump, aireplay)  
- WPA/WPA2-PSK cracking (aircrack)  
- Support for various wireless attack techniques

## Practical Use Cases
- Audit network encryption and misconfigurations  
- Recover weak pre-shared keys in lab environments  
- Demonstrate need for WPA2/WPA3 and strong passphrases

## Tips
- Always test only on networks you own or have explicit permission to assess.  
- Use with good capture hardware and antennas for reliable results.
