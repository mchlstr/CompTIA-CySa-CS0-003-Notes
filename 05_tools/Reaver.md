# Reaver

## What it is
Tool for brute-forcing Wi-Fi Protected Setup (WPS) PINs.

## Purpose
Test the security of WPS-enabled wireless networks.

## Key Features
- Automated WPS PIN recovery  
- Works on WPA/WPA2 networks  
- Supports retries and timing adjustments

## Practical Use Cases
- Security testing of lab wireless networks  
- Demonstrate WPS vulnerabilities to stakeholders  
- Educational penetration testing

## Tips
- Only test networks you control or have explicit authorization for  
- Modern routers may limit attack effectiveness
