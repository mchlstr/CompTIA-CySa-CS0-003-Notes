# Nmap

## What it is
Powerful network discovery and security auditing tool.

## Purpose
Enumerate hosts, ports, and services; detect OS and vulnerabilities.

## Key Features
- TCP/UDP port scanning  
- OS and service fingerprinting  
- Scriptable NSE modules

## Practical Use Cases
- Reconnaissance for security assessments  
- Inventory of networked assets  
- Vulnerability validation

## Tips
- Combine with NSE scripts for deeper testing  
- Use responsibly to avoid alerting administrators
