# PsExec

## What it is
Windows administration and remote execution tool.

## Purpose
Execute processes on remote systems and manage networked Windows hosts.

## Key Features
- Remote command execution  
- Interactive session support  
- Integration with Windows SYSTEM account

## Practical Use Cases
- Red team lateral movement exercises  
- Remote troubleshooting and management  
- Testing privileged account protections

## Tips
- Requires administrative access  
- Often flagged by EDR for suspicious activity
