# Maltego

## What it is
Graphical link analysis tool for open-source intelligence (OSINT).

## Purpose
Visualize relationships between people, domains, IPs, and organizations.

## Key Features
- Entity-based visualizations  
- Integration with public and commercial data sources  
- Automated link discovery and reporting

## Practical Use Cases
- Investigate threat actors  
- Map infrastructure in reconnaissance  
- Corporate investigations and risk assessments

## Tips
- Requires API keys for some data sources  
- Export findings for reporting and presentations
