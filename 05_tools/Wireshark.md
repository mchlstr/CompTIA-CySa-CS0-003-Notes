# Wireshark

## What it is
GUI-based network protocol analyzer for packet-level inspection.

## Purpose
Capture, visualize, and analyze network traffic for troubleshooting and security.

## Key Features
- Decode hundreds of protocols  
- Filter and search packets  
- Export data for reporting

## Practical Use Cases
- Incident response traffic analysis  
- Network performance troubleshooting  
- Protocol behavior research

## Tips
- Use capture filters to reduce noise  
- Combine with tcpdump for scripted captures
