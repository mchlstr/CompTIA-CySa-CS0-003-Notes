## **CySA+ CS0-003 Acronyms Glossary**

### **Compliance / Governance**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| CIS | Center for Internet Security | Provides benchmarks for secure configuration |
| ISO | International Organization for Standardization | Global standards organization |
| MOU | Memorandum of Understanding | Agreement between parties |
| PCI DSS | Payment Card Industry Data Security Standard | Security standard for payment card processing |
| SLA | Service-Level Agreement | Defines expected service performance |
| SLO | Service-Level Objective | Specific measurable service targets |

---

### **Development / Software Security**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| JSON | JavaScript Object Notation | Lightweight data-interchange format |
| LFI | Local File Inclusion | Vulnerability allowing local files to be executed or viewed |
| OWASP | Open Web Application Security Project | Community project providing web security guidance |
| RFI | Remote File Inclusion | Vulnerability allowing remote files to be included/executed |
| SDLC | Software Development Life Cycle | Framework for developing secure software |
| XML | Extensible Markup Language | Standard for structured data exchange |

---

### **Encryption / Data Protection**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| CHD | Cardholder Data | Sensitive payment card information |
| DLP | Data Loss Prevention | Technology to prevent sensitive data from leaving an organization |
| PII | Personally Identifiable Information | Data that can identify an individual |
| PKI | Public Key Infrastructure | System for managing digital certificates and encryption keys |
| SSL | Secure Sockets Layer | Protocol for encrypted communication over networks |

---

### **Identity and Access Management**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| CASB | Cloud Access Security Broker | Security layer between cloud service users and providers |
| MFA | Multifactor Authentication | Requires multiple forms of verification to access a system |
| PAM | Privileged Access Management | Controls access to high-privilege accounts |
| SSO | Single Sign-On | Allows users to log in once for multiple services |

---

## **Incident Response & Security Operations**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| BC | Business Continuity | Ensuring critical operations continue during a disruption |
| CERT | Computer Emergency Response Team | The team that handles cybersecurity incidents |
| CSIRT | Cybersecurity Incident Response Team | Internal team responsible for incident handling |
| DR | Disaster Recovery | Steps to restore IT systems after a disruption |
| XDR | Extended Detection and Response | Integrated detection and response across multiple security layers |

---

### **Network and Infrastructure**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| DNS | Domain Name Service | Resolves domain names to IP addresses |
| IP | Internet Protocol | Fundamental protocol for addressing and routing packets |
| SASE | Secure Access Secure Edge | Framework combining network security and WAN capabilities |
| SDN | Software-Defined Networking | Centralized control of network resources via software |
| TCP | Transmission Control Protocol | Core protocol for reliable internet communication |

---
## **Threat Intelligence**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| APT | Advanced Persistent Threat | Sophisticated, long-term cyberattack by well-resourced actors |
| C2 | Command and Control | The mechanism by which attackers communicate with compromised systems |
| IoC | Indicators of Compromise | Signs that a system has been breached or is under attack |
| STIX | Structured Threat Information Expression | Standard language for representing cyber threat intelligence data |
| TAXII | Trusted Automated eXchange of Indicator Information | Protocol for exchanging cyber threat intelligence (e.g., IoCs) between systems |
| TTP | Tactics, Techniques, and Procedures | Attack behavior patterns of threat actors |

---
### **Vulnerability and Security Tools**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| CVSS | Common Vulnerability Scoring System | Standardized scoring system for vulnerability severity |
| GDB | GNU Debugger | Tool for analyzing program execution, debugging binaries |
| MSF | Metasploit Framework | Exploitation framework for testing vulnerabilities |
| OpenVAS | Open Vulnerability Assessment Scanner | Tool for scanning network and system vulnerabilities |
| SIEM | Security Information and Event Management | Platform for collecting, correlating, and analyzing logs |
| SOAR | Security Orchestration, Automation, and Response | Platform for automating and orchestrating security tasks |
| ZAP | Zed Attack Proxy | Web application security testing tool |

---

### **Web / Email Security**

| Acronym | Spelled Out | Notes |
| ----- | ----- | ----- |
| DKIM | DomainKeys Identified Mail | Email authentication method to prevent spoofing |
| DMARC | Domain-based Message Authentication, Reporting, and Conformance | Email authentication & reporting framework |
| SPF | Sender Policy Framework | Email validation to prevent address spoofing |
