## CySA+ CS0-003 Key Term Glossary

| Term | Definition |
| :---- | :---- |
| 802.1X | A standard for encapsulating EAP (Extensible Authentication Protocol) communications over a LAN or wireless LAN, providing port-based authentication. |
| AbuseIPDB | A community-driven database that keeps track of IP addresses reported for abusive behavior. |
| Access Control List (ACL) | A list of permitted and denied network connections based on either IP addresses, ports, or applications in use. |
| Advanced Persistent Threat (APT) | An attacker who establishes a long-term presence on a network to gather sensitive information. An attacker's ability to obtain, maintain, and diversify access to network systems using exploits and malware. |
| Aircrack-ng Suite | A suite of utilities designed for wireless network security testing. |
| Allowlisting | The process of allowing only known applications, services, traffic, and other transmissions to and from your systems. |
| Angry IP Scanner | A tool used to quickly scan an IP range to determine which hosts are active, as well as gather information like host names, open ports, and running services. |
| Anomaly Analysis | A network monitoring system that uses a baseline of acceptable outcomes or event patterns to identify events that fall outside the permissible range. |
| Antivirus (AV) | Software capable of detecting and removing virus infections and other types of malware. |
| Application Programming Interface (API) | A library of programming utilities used to enable software developers to access functions of another application. |
| Arachni | An open-source web scanner application. |
| Arbitrary Code Execution | A vulnerability that allows an attacker to run their own code or a module that exploits such a vulnerability. |
| Attribute-Based Access Control (ABAC) | An access control technique that evaluates a set of attributes that each subject possesses to determine if access should be granted. |
| Attribution | Identification and publication of an attacker’s methods, techniques, and tactics as practical threat intelligence. |
| Beaconing | Repetitive small packets sent to the same external IP at regular intervals, often indicative of Command-and-control (C2) traffic. |
| Behavior-based Detection | A malware detection method that evaluates an object based on its intended actions before it can actually execute that behavior. |
| Behavioral Analysis | A network monitoring system that detects changes in standard operating data sequences and identifies abnormal sequences. |
| Black Hat Hacker | An unauthorized hacker, a criminal. |
| Blocklisting | The process of blocking known applications, services, traffic, and other transmissions to and from your systems. |
| Broken Authentication | A software vulnerability where the authentication mechanism allows an attacker to gain entry. |
| Buffer Overflow | An attack in which data goes past the boundary of the destination buffer and begins to corrupt adjacent memory. |
| Bug Bounty | A way for companies to crowdsource security testing of their software services and applications to identify and address potential security issues. |
| Building Automation System (BAS) | Components and protocols that facilitate the centralized configuration and monitoring of mechanical and electrical systems within offices and data centers. |
| Burp Suite | A proprietary interception proxy and web application assessment tool used for analyzing and modifying client-server traffic. |
| Business Continuity Plan (BCP) | The plans and processes used during a response to a disruptive event. |
| Business Email Compromise (BEC) | An impersonation attack in which the attacker gains control of an employee's account and uses it to convince other employees to perform fraudulent actions. |
| Business Impact Analysis (BIA) | A systematic activity that identifies organizational risks and determines their effect on ongoing, mission-critical operations. |
| Canonicalization Attack | An attack method where input characters are encoded in such a way as to evade vulnerable input validation measures. |
| Cardholder Data (CHD) | Data protected under PCI DSS; unauthorized access or storage indicates serious compliance and security issues. |
| Chain of Custody | The record of evidence history from collection, to presentation in court, to disposal. |
| Clickjacking | A type of hijacking attack that forces a user to unintentionally click a link that is embedded in or hidden by other web page elements. |
| Cloud Access Security Broker (CASB) | Enterprise management software designed to mediate access to cloud services by users, enforcing policy and visibility across SaaS applications. |
| Code Injection | An exploit technique that runs malicious code with the identification number of a legitimate process. |
| Command and Control (C2) | An infrastructure of hosts and services with which attackers direct, distribute, and control malware over botnets. |
| Common Vulnerabilities and Exposures (CVE) | A commonly used scheme for identifying vulnerabilities was developed by MITRE and adopted by NIST. |
| Common Vulnerability Scoring System (CVSS) | A risk management approach to quantifying vulnerability data and then taking into account the degree of risk to different types of systems or information. |
| Compensating Control | A type of security control that acts as a substitute for a principal control. |
| Containerization | A type of virtualization applied by a host operating system to provision an isolated execution environment for an application (e.g., Docker, Kubernetes). |
| Continuous Delivery | A software development method where application and platform requirements are frequently tested and validated for immediate availability. |
| Continuous Deployment | A software development method in which application and platform updates are rapidly committed to production. |
| Continuous Integration | A software development method where code updates are tested and committed to a development or build server/code repository rapidly. |
| Cookie Poisoning | Modifying the contents of a cookie after it has been generated to exploit vulnerabilities in a web application. |
| Correlation Rule | A statement in a SIEM that matches certain conditions as expressed using logical expressions and operators to identify significant incidents. |
| Covert Channels | A communication path that allows data to be sent outside of the network without alerting any intrusion detection or data loss countermeasures. |
| Credential Stuffing | A brute force attack in which stolen user account names and passwords are tested against multiple websites. |
| Credentialed Scan | A vulnerability scan in which the scanner is given a user account to log on to target systems for in-depth analysis. |
| Cross-Site Request Forgery (XSRF/CSRF) | A malicious script hosted on an attacker's site that can exploit a session started on another site in the same browser. |
| Cross-Site Scripting (XSS) | A malicious script hosted on an attacker's site or injected onto a trusted site is designed to compromise clients browsing the trusted site. |
| Cyber Threat Intelligence | Investigation, collection, analysis, and dissemination of information about emerging threats and threat sources to provide data about the external threat landscape. |
| Data Acquisition | The method and tools used to create a forensically sound copy of data from a source device, such as system memory or a hard disk. |
| Data Exfiltration | The unauthorized transfer of data from a computer or other device. |
| Data Loss Prevention (DLP) | A software solution that detects and prevents sensitive information from being stored on unauthorized systems or transmitted over unauthorized networks. |
| Decompiler | A software that translates a binary or low-level machine language code into a higher-level code. |
| Deidentification | Methods and technologies that remove identifying information from data before it is distributed. |
| Detective Control | A control that may not prevent or deter access, but will identify and record any attempted or successful intrusion. |
| Deterrent Control | A type of security control that discourages intrusion attempts. |
| DevSecOps | A combination of software development, security operations, and systems operations is achieved by integrating each discipline with the others. |
| Diamond Model of Intrusion Analysis | A framework for analyzing cybersecurity incidents by exploring the relationships between four core features: adversary, capability, infrastructure, and victim. |
| Digital Forensics | The process of gathering and submitting computer evidence to trial, and interpreting that evidence by providing expert analysis. |
| Digital Rights Management (DRM) | Copyright protection technologies for digital media aim to mitigate the risk of unauthorized copying. |
| Directory Traversal | An application attack that allows access to commands, files, and directories that may or may not be connected to the web document root directory. |
| Disassembler | A computer program that translates machine language into assembly language. |
| Domain Generation Algorithm (DGA) | A method used by malware to evade block lists by dynamically generating domain names for C2 networks. |
| Domain-Based Message Authentication, Reporting, and Conformance (DMARC) | A framework for ensuring proper application of SPF and DKIM utilizing a policy published as a DNS record. |
| DomainKeys Identified Mail (DKIM) | Provides a cryptographic authentication mechanism for mail utilizing a public key published as a DNS record. |
| Dropper | Malware designed to install or run other types of malware embedded in a payload on an infected host. |
| EDR (Endpoint Detection and Response) | A software agent that collects system data and logs for analysis by a monitoring system to provide early detection of threats at the host level. |
| Email Harvesting | An Open-Source Intelligence (OSINT) technique for gathering email addresses for a domain. |
| Endpoint Protection Platform (EPP) | A software agent and monitoring system that performs multiple security tasks, including antivirus, HIDS/HIPS, firewall, DLP, and file encryption. |
| Enumeration | The process to identify and scan network ranges and hosts belonging to the target, and map the attack surface. |
| Error Handler | Coding methods to anticipate and deal with exceptions thrown during the execution of a process. |
| Execution Control | The process of determining what additional software may be installed on a client or server beyond its baseline. |
| Federation | A process that provides a shared login capability across multiple systems and enterprises, enabling trust between domains. |
| File Carving | The process of extracting data from a computer when that data has no associated file system metadata. |
| File Inclusion | A web application vulnerability that allows an attacker to either download a file from an arbitrary location or upload an executable/script file. |
| Fingerprinting | Identifying the type and version of an operating system (or server application) by analyzing its responses to network scans. |
| Firewalking | A reconnaissance technique to enumerate firewall configuration and attempt to probe hosts behind it. |
| Footprinting | A phase of an attack where the attacker gathers information about the target, mapping out the network layout and IP address usage. |
| Forward Proxy | A server that mediates communications between a client and another server. |
| Fuzzing | A dynamic code analysis technique that involves sending a running application random, unusual input to evaluate its response. |
| Golden Ticket | A Kerberos ticket that can grant other tickets in an Active Directory environment, providing extensive access. |
| Google Hacking | Open-source intelligence techniques that use Google search operators to locate vulnerable web servers and applications. |
| Gray Hat Hacker | A semi-authorized hacker who sometimes acts for good or malicious purposes. |
| Hacktivist | A politically-motivated hacker who targets governments or individuals to advance their political ideologies. |
| Hardware Root of Trust (ROT) | A cryptographic module embedded within a computer system that can endorse trusted execution and attest to boot settings and metrics. |
| Hardware Security Module (HSM) | An appliance for generating and storing cryptographic keys that is less susceptible to tampering and insider threats than software-based storage. |
| Hashcat | A command-line tool used to perform brute force and dictionary attacks against password hashes. |
| Heuristic Analysis | A method that uses feature comparisons and likenesses rather than specific signature matching to identify whether the target of observation is malicious. |
| Honeypot | A host set up with the purpose of luring attackers away from actual network components and/or discovering attack strategies. |
| hping | An open-source spoofing tool that provides the ability to craft network packets to exploit vulnerable firewalls and IDS/IPS. |
| Idempotence | A property of Infrastructure as Code (IaC) is that an automation or orchestration action always produces the same result, regardless of the component's previous state. |
| Identity and Access Management (IAM) | A security process that provides identification, authentication, and authorization mechanisms for users, computers, and other entities. |
| Indicator of Attack (IoA) | A term used for evidence of an intrusion attempt that is in progress. |
| Indicator of Compromise (IoC) | A residual sign that an asset or network has been successfully attacked or is continuing to be attacked. |
| Industrial Control Systems (ICS) | A network that manages embedded devices, used for systems like electrical power stations and manufacturing. |
| Infrastructure as Code (IaC) | A provisioning architecture in which the deployment of resources is performed by scripted automation and orchestration. |
| Input Validation | Any technique used to ensure that the data entered into a field or variable in an application is handled appropriately by that application. |
| Insider Threat | People who have authorized access to an organization’s network, policies, procedures, and business practices may cause harm intentionally or unintentionally. |
| Interception Proxy | Software that sits between a client and server and allows requests and responses to be analyzed and modified. |
| Internet of Things (IoT) | A group of objects that are connected to the wider Internet by using embedded electronic components. |
| Intrusion Detection System (IDS) | A software and/or hardware system that scans, audits, and monitors the security infrastructure for signs of attacks in progress. |
| Intrusion Prevention System (IPS) | An IDS that can actively block an attack. |
| Isolation | A mitigation strategy that involves removing an affected component from whatever larger environment it is a part of. |
| Jumpbox | A hardened server that provides access to other hosts within a screened subnet. |
| Known Threats | A threat that can be identified using basic signature or pattern matching. |
| Lateral Movement | A technique to progressively move through a network to search for the key data and assets that are ultimately the target of an attack campaign. |
| Legal Hold | A process designed to preserve all relevant information when litigation is reasonably expected to occur. |
| Living Off the Land | Exploit techniques that use standard system tools and packages to perform intrusions. |
| Lockheed Martin Kill Chain | An attack framework that describes the stages by which a threat actor progresses a network intrusion. |
| Logging Levels | Controls the verbosity of logs (e.g., info, warning, error, debug) to balance data volume with visibility. |
| MAC Filtering | Applying an access control list to a switch or access point so that only clients with approved MAC addresses can connect to it. |
| Machine Learning (ML) | A component of AI that enables a machine to develop strategies for solving a task given a labeled dataset without further explicit instructions. |
| Malicious Process | A process executed without proper authorization from the system owner for the purpose of damaging or compromising the system. |
| Maltego | An open-source tool used by cybersecurity analysts for data mining, reconnaissance, and enumeration. |
| Malware | Any software intentionally designed to cause damage to a computer, server, client, or computer network. |
| Mandatory Access Control (MAC) | An access control model where resources are protected by inflexible, system-defined rules based on clearance levels. |
| Measured Boot | A UEFI feature that gathers secure metrics to validate the boot process in an attestation report. |
| Microservices | A software architecture where components of the solution are conceived as highly decoupled services that can be developed, tested, and deployed independently. |
| Mimikatz | An open-source application that allows users to view and save authentication credentials to perform pass-the-hash attacks. |
| MITRE ATT&CK Framework | A knowledge base for listing and explaining specific adversary tactics, techniques, and common knowledge or procedures. |
| Mobile Device Management (MDM) | The process and supporting technologies for tracking, controlling, and securing an organization's mobile infrastructure. |
| Multifactor Authentication (MFA) | An authentication scheme that requires the user to present at least two different factors as credentials. |
| Nation-State | A group of attackers with exceptional capability, funding, and organization, with an intent to hack a network or system, often affiliated with a government. |
| National Vulnerability Database (NVD) | A superset of the CVE database, maintained by NIST, that contains additional analysis, criticality metrics (CVSS), and fix information. |
| NDR (Network Detection and Response) | A tool that provides network-based traffic analysis to detect C2, lateral movement, and data exfiltration. |
| Netcat (nc) | A utility for reading and writing raw data over a network connection, often used as a listener for remote shells. |
| NetFlow | A Cisco-developed means of reporting network flow information (metadata) to a structured database. |
| Network Access Control (NAC) | A general term for the collected protocols, policies, and hardware that authenticate and authorize access to a network at the device level. |
| Network Segmentation | Limiting attacker movement by dividing networks into roles or sensitivity levels. |
| Nmap | A versatile port scanner used for topology, host, service, and OS discovery and enumeration. |
| Non-credentialed Scan | A vulnerability scan that sends test packets against a target without logging onto the system or host. |
| Normalization | A process where data is reformatted or restructured to facilitate scanning and analysis, or a string is stripped of illegal characters and converted to an accepted character set. |
| OAuth | A delegated authorization framework for RESTful APIs that enables apps to obtain limited access to a user's data without giving away the user's password. |
| On Path Attack | Also known as Man-in-the-Middle (MitM), an attack where the attacker sits between two communicating hosts and transparently captures, monitors, and relays all communication. |
| Open-Source Intelligence (OSINT) | A method of obtaining information about a person or organization through public records, websites, and social media. |
| OpenID Connect (OIDC) | An authentication protocol that can be implemented as special types of OAuth flows with precisely defined token fields. |
| OpenIOC | A framework developed by Mandiant that uses XML-formatted files for supplying codified information to automate incident detection and analysis. |
| OpenVAS | An open-source vulnerability scanner that began its development from the Nessus codebase. |
| OWASP Zed Attack Proxy (ZAP) | An open-source interception proxy and web application assessment tool written in Java. |
| Packet Capture | The inspection of network traffic at the packet level to identify C2 traffic, exfiltration, or exploits. |
| Packet Sniffer | A piece of hardware or software that records data from frames as they pass over network media. |
| Parameter-based Queries | A technique that defends against SQL injection by incorporating placeholders in a SQL query. |
| Pass the Hash | A network-based attack where an attacker steals hashed user credentials and uses them as-is to authenticate to the network. |
| Password Spraying | A brute force attack in which multiple user accounts are tested with a dictionary of common passwords. |
| Passwordless Authentication | Allows login to a computer system without entering a password or any other knowledge-based secret. |
| Persistence | The ability of a threat actor to maintain covert access to a target host or network. |
| Personally Identifiable Information (PII) | Data that can be used to identify, contact, or impersonate an individual. Privacy laws often mandate protection. |
| Phishing | The fraudulent practice of sending emails purporting to be from reputable companies to induce individuals to reveal personal information. |
| Physical Access Control System (PACS) | Components and protocols that facilitate the centralized configuration and monitoring of security mechanisms within offices and data centers. |
| Pivoting | The use of one infected computer to attack a different computer on the same network to bypass restrictions, such as firewall configurations. |
| Playbook | A standard operating procedure that tells analysts exactly what they should do in response to different scenarios. |
| Port Forwarding | An attacker uses a host as a pivot to access one of its open TCP/IP ports to send traffic from this port to a port of a host on a different subnet. |
| Port Scan | Enumerating the status of TCP and UDP ports on a target system using software tools. |
| Posture Assessment | The process of assessing an endpoint for compliance with a health policy. |
| Preventative Control | A control that acts to eliminate or reduce the likelihood that an attack can succeed. |
| Privilege Escalation | The practice of exploiting flaws in an operating system or other application to gain a greater level of access than was intended. |
| Privileged Access Management (PAM) | A system that controls and monitors the usage of administrative and other elevated-privilege accounts. |
| Programmable Logic Controller (PLC) | A type of computer designed for deployment in an industrial setting that can automate and monitor mechanical systems. |
| Proprietary (Threat Intelligence) | Threat intelligence is provided as a commercial service offering, subject to a subscription fee. |
| PsExec | A tool developed as an alternative to Telnet that utilizes the Windows SYSTEM account for privilege escalation and lateral movement. |
| Public Key Infrastructure (PKI) | A system that provides identity validation via certificates. SOCs track expired/rogue certificates and MITM attempts. |
| Qualys | A cloud-based vulnerability management solution with installed sensor agents that upload data to a cloud platform for analysis. |
| Race Conditions | A software vulnerability where the resulting outcome from execution processes is directly dependent on the order and timing of certain events. |
| Reaver | A command-line tool used to perform brute force attacks against WPS-enabled access points. |
| Recertification | A manual review of accounts, permissions, configurations, and clearance levels at a given interval. |
| Regular Expression (regex) | A group of characters that describes how to execute a specific search pattern on a given text. |
| Remediation | The overall process of reducing exposure to the effects of risk factors. |
| Remote Code Execution | A vulnerability that allows an attacker to transmit code from a remote host for execution on a target host. |
| Representational State Transfer (REST) | A software architectural style that defines a set of constraints to be used for creating web application services. |
| Reputation Data | Blacklists of known threat sources, such as malware signatures, IP address ranges, and DNS domains. |
| Reverse Engineering | The process of analyzing the structure of hardware or software to reveal more about how it functions. |
| Reverse Proxy | A type of proxy server that protects servers from direct contact with client requests. |
| Risk Acceptance | A risk response that involves determining that a risk falls within the organization’s risk appetite and that no countermeasures beyond ongoing monitoring will be needed. |
| Risk Avoidance | A risk response that involves ceasing an activity that presents risk. |
| Risk Mitigation | A risk response that reduces a risk to fit within an organization's risk appetite. |
| Risk Transference | A risk response that involves moving or sharing the responsibility of risk to another entity. |
| Role-Based Access Control (RBAC) | An access control model where resources are protected by ACLs managed by administrators, providing permissions based on job functions. |
| Rootkit | A class of malware that modifies system files (often at the kernel level) to conceal its presence. |
| Runbook | An automated version of a playbook that leaves clearly defined interaction points for human analysis. |
| Sandboxing | A computing environment isolated from a host system to guarantee that the environment runs in a controlled, secure fashion. |
| SASE (Secure Access Service Edge) | An architecture that integrates networking and security into a cloud-delivered service, monitoring traffic through SASE gateways. |
| Scans/sweeps | A high rate of connection attempts across multiple hosts or ports, often for reconnaissance. |
| ScoutSuite | An open-source tool written in Python used to audit instances and policies created on multicloud platforms. |
| Screened Subnet | A physical or logical subnetwork that contains and exposes an organization's external-facing services to an untrusted network like the Internet. |
| Script Kiddie | An individual who uses other people’s tools to conduct their attacks, as they do not have the skills to make their own tools. |
| Secure Boot | A UEFI feature that prevents unwanted processes from executing during the boot operation. |
| Secure Enclave | An encrypted container for sensitive data created by a trusted process using CPU security extensions. |
| Secure Sockets Layer (SSL) Inspection | The process of decrypting and inspecting encrypted traffic to detect threats, balanced with privacy considerations. |
| Security Assertions Markup Language (SAML) | An XML-based data format used to exchange authentication information between a client and a service. |
| Security Control | A mechanism that mitigates vulnerabilities and risk to ensure the confidentiality, integrity, availability, nonrepudiation, and authentication of data. |
| Security Development Life Cycle (SDL) | Microsoft's security framework for application development that supports dynamic development processes. |
| Security Information and Event Management (SIEM) | Software or hardware that provides real-time analysis of security alerts generated by network hardware and applications. |
| Security Intelligence | The process involves generating, collecting, processing, analyzing, and disseminating to provide insights into the security status of information systems. |
| Security Operations Center (SOC) | A location where security professionals monitor and protect critical information assets in an organization. |
| Security Orchestration, Automation, and Response (SOAR) | A class of security tools that facilitates incident response, threat hunting, and security configuration by orchestrating automated runbooks. |
| Segmentation | A mitigation strategy that achieves the isolation of a host or group of hosts using network technologies and architecture. |
| Sensitive Data Exposure | A software vulnerability where an attacker is able to circumvent access controls and retrieve confidential or sensitive data. |
| Separation of Duties | A means of establishing checks and balances to prevent insider threats from compromising critical systems or procedures. |
| Server-Side Request Forgery (SSRF) | A type of cyber-attack in which an attacker can send a request on behalf of a web application, potentially to internal systems. |
| Serverless | A software architecture that runs functions within virtualized runtime containers in a cloud rather than on dedicated server instances. |
| Service-Oriented Architecture (SOA) | A software architecture where components of the solution are conceived as loosely coupled services not dependent on a single platform type or technology. |
| Session Hijacking | A type of spoofing attack where the attacker disconnects a host and then replaces it with their own machine, spoofing the original host's IP address. |
| Shellcode | Any lightweight code designed to run an exploit on the target, which may include any type of code format from scripting languages to binary code. |
| Shodan | A search engine optimized for identifying vulnerable Internet-attached devices. |
| SIEM (Security Information and Event Management) | A system for aggregating logs and correlating events across hosts, users, and networks. |
| sigcheck | A Sysinternals utility that allows you to verify root certificates in the local store against Microsoft's master trust list. |
| Simple Object Access Protocol (SOAP) | An XML-based web services protocol that is used to exchange messages. |
| Single Pane of Glass | A central point of access for all the information, tools, and systems a security team needs to monitor, manage, and secure an IT environment. |
| Single Sign-On (SSO) | An authentication technology that enables a user to authenticate once and receive authorizations for multiple services. |
| Sinkhole | A DoS attack mitigation strategy that directs the traffic that is flooding a target IP address to a different network for analysis. |
| SOAR (Security Orchestration, Automation, and Response) | A tool used for automated incident response and the reduction of repetitive tasks through workflows and playbooks. |
| Software-Defined Networking (SDN) | A network architecture with a centralized control plane is useful for automated isolation of compromised systems. |
| Spam | Unsolicited and unwanted junk email sent out in bulk to an indiscriminate recipient list. |
| Spear Phishing | An email spoofing attack targeting a specific organization or individual by seeking unauthorized access to sensitive information. |
| Splunk | A market-leading big data information gathering and analysis tool that can import and analyze machine-generated data. |
| Spoofing | A software-based attack where the goal is to assume the identity of a user, process, address, or other unique identifier. |
| SQL Injection | An attack consisting of the insertion or injection of an SQL query via input data from the client to a web application. |
| Staging Area | A place where an adversary begins to collect data in preparation for data exfiltration. |
| Static Code Analysis | The process of reviewing uncompiled source code either manually or using automated tools. |
| Steganography | The practice of concealing data within another file, message, image, or video. |
| Strings | A tool that extracts human-readable content from a binary, which can identify C2 endpoints or encoded commands. |
| Structured Threat Information eXpression (STIX) | A standard terminology for IoCs and ways of indicating relationships between them, expressed in JSON format. |
| Supply Chain Threats | Threats that originate from vulnerabilities in the supply chain of hardware or software. |
| Sweep | A scan directed at multiple IP addresses to discover whether a host responds to connection requests for particular ports. |
| Sysinternals | A suite of tools designed to assist with troubleshooting and investigating security issues in Windows. |
| System Hardening | The process of securing a system's configuration and settings to reduce its attack surface through patching, service minimization, and secure configurations. |
| System-on-Chip (SoC) | A processor that integrates the platform functionality of multiple logical controllers onto a single chip. |
| Tabletop Exercise (TTX) | An exercise that uses an incident scenario against a framework of controls or a red team in a discussion-based format. |
| Tactics, Techniques, and Procedures (TTPs) | A description of how adversaries operate: tactics are goals, techniques are methods, and procedures are specific implementations. |
| tcpdump | A data-network packet analyzer computer program that runs under a command-line interface. |
| Threat Actors | Those who wish to harm networks or steal secure data. |
| Threat Hunting | A cybersecurity technique designed to detect the presence of threats that have not been discovered by normal security monitoring. |
| Threat Modeling | The process of identifying and assessing the possible threat actors and attack vectors that pose a risk to the security of an app, network, or other system. |
| Time of Check to Time of Use (TOCTTOU) | A potential vulnerability that occurs when there is a change between when an app checked a resource and when the app used the resource. |
| Time Synchronization | The process of ensuring all systems and devices share a consistent time source (e.g., NTP), which is critical for event correlation. |
| Tokenization | A deidentification method where a unique token is substituted for real data. |
| Traffic Spikes | A sharp increase in connection requests in comparison with a given baseline. |
| Trusted Automated eXchange of Indicator Information (TAXII) | A protocol for supplying codified information to automate incident detection and analysis. |
| Trusted Platform Module (TPM) | A specification for hardware-based storage of digital certificates, keys, hashed passwords, and other user and platform identification information. |
| UEBA (User and Entity Behavior Analytics) | A system that can provide automated identification of suspicious activity by user accounts and computer hosts. |
| Unified Extensible Firmware Interface (UEFI) | A type of system firmware providing support for 64-bit CPU operation at boot, full GUI and mouse operation at boot, and better boot security. |
| Unknown Threats | A threat that cannot be identified using basic signature or pattern matching. |
| URL Analysis | An activity performed to identify whether a link is already flagged on a reputation list or what malicious script might be coded within it. |
| Virtual Desktop Infrastructure (VDI) | A virtualization implementation that separates the personal computing environment from a user's physical computer. |
| Virtual Private Cloud (VPC) | A private network segment made available to a single cloud consumer within a public cloud. |
| Virtualization | A technology where a host computer is installed with a hypervisor to manage multiple guest operating systems or virtual machines (VMs). |
| VirusTotal | A tool that inspects items with over 70 antivirus scanners and URL/domain blacklisting services. |
| Vulnerability Assessment | An evaluation of a system's security and compliance requirements based on its configuration state. |
| Vulnerability Scanner | A hardware appliance or software application configured with a list of known weaknesses and exploits that can scan for their presence. |
| Watermarking | Methods and technologies that apply a unique anti-tamper signature or message to a copy of a document. |
| Web Application Firewall (WAF) | A firewall designed specifically to protect software running on web servers from code injection and DoS attacks. |
| White Hat Hacker | An ethical or authorized hacker. |
| WHOIS | A public listing of all registered domains and their registered administrators. |
| Wireshark | A free and open-source GUI-based packet analyzer used for network troubleshooting, analysis, and protocol development. |
| Write Blockers | A forensic tool to prevent a capture or analysis device from changing data on a target disk or media. |
| XML Bomb (Billion Laughs Attack) | An attack where XML encodes entities that expand to exponential sizes, consuming memory on the host and potentially crashing it. |
| XML External Entity (XXE) | An attack that embeds a request for a local resource within an XML document. |
| Yara | A multi-platform program for identifying, classifying, and describing malware samples using rules that match string combinations. |
| Zeek (Bro) | A hybrid tool that passively monitors a network like a sniffer and only logs data of potential interest. |
| Zero Trust | A security concept centered on the belief that organizations should not automatically trust anything inside or outside their perimeters and must verify everything that connects to their systems. |
| Zero-day Exploit | An unknown exploit in the wild that exposes a vulnerability in software or hardware and can create complicated problems well before anyone realizes something is wrong. |
